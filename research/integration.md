# Research integration: starting map

This note records candidate connections only; no claim is attributed to Levin unless independently sourced to a primary source and timestamp.

| Candidate bridge | Potential formalization | Falsifiable research question |
|---|---|---|
| Anatomical target morphology and compactification | Treat many microstates as equivalent when they converge to the same stable anatomical outcome under a defined perturbation set. | Do perturbation-response trajectories cluster by target morphology more strongly than by initial molecular state? |
| Multiscale agency and controllability | Compare control authority and reachable states across cellular, tissue, and organismal scales. | Does a scale-specific intervention change the reachable target set while holding lower-level perturbation magnitude constant? |
| Bioelectric pattern memory and state estimation | Model physiological pattern memory as a distributed state variable with measurable reset and recall behavior. | Can a blinded perturbation protocol predictably write, erase, and retrieve a pattern memory? |
| Goal-directed dynamics and behavioral equivalence | Test whether distinct interventions share a functional endpoint despite different trajectories. | Does endpoint equivalence persist on preregistered out-of-distribution perturbations? |
