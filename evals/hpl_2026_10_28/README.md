## Compactification experiment (original proposal)

Given physical state x, action u, goal region G and horizon T, test whether a compressed state phi(x) preserves intervention-conditioned target probabilities:

    sup_{u in U} abs(P(X_T in G | x,u) - P(X_T in G | phi(x),u)) <= epsilon

Such an equation requires an explicit model or estimation protocol for the right-hand conditional. Hold out perturbations and compare matched-capacity controllers, observation-only embeddings, randomized features and the full state. Distinguish a test of action-relevant compression from confirmation of any Platonic ontology.
